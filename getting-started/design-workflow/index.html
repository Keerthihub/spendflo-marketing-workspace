Design workflow

Foundations first, artifact second. Designers never restyle from scratch — they compose from tokens and documented patterns, so every new piece lands on-brand without review cycles.

StableOwner · Brand teamUpdated · Jul 2026v1.0

Principle

The system is generative: if a decision already exists here, reuse it; if it doesn’t, propose it through contribution rather than inventing a one-off. One-offs are how brands drift.

The workflow

  • 01 · Frame it. Identify which System you’re producing (deck, email, case study, social) and open its page — the anatomy there is the starting file, not a blank canvas.
  • 02 · Pull foundations. Colours from Colour, styles from Typography, marks from Brand assets. Copy tokens, don’t eyeball values.
  • 03 · Compose. Keep one accent, generous whitespace, and mono labels for meta. The artifact previews on each System page show the target feel in motion.
  • 04 · Check & ship. Run the page’s do/don’t list, confirm clear space and contrast, export with the documented settings.

Before you ship

  • Only documented lockups — never a recoloured or reconstructed logo.
  • Magenta is an accent, never body text; maroon is the signature surface.
  • Type comes from the documented scale — no in-between sizes.
  • If you had to invent something, it goes back into the system via contribution.
