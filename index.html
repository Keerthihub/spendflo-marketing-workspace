How this system works
Foundations
The primitives — voice, logo, colour, type, icons, agents, assets. Change one here and it changes everywhere.
Systems
The deliverables — deck, website, case study, emailer, signature, social. Each one is built from the foundations.
Tokens
One source of truth. Every colour, size, and radius is a named token you can copy or download.
Tools
Live playgrounds — type, icons, email signature — so you produce on-brand output without guessing.
How to use it
01Start with the foundationsRead voice and colour first — they set the tone for everything else.
02Pick the system you’re buildingJump to Deck, Emailer, Website and so on — each shows a live, animated example of the finished artifact.
03Copy the tokensGrab colours, type, and icons straight from the page, or download the full token file from Brand assets.
04Ship it on-brandUse the playgrounds to fine-tune, then hand off. Press ⌘K anytime to jump between pages.
